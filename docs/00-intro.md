# 00 介绍

## 它是什么

一个本地运行的 LLM 调试器。提供一个网页界面，让你**完全控制每次模型调用的输入输出**，
包括强制改写 LLM 已经说过的话、伪造工具结果、在任意一轮中间分叉，
然后看模型在"被你改过的历史"上下文中如何继续。

目标读者：构建 agent / 调 prompt / 排查工具调用问题 / 想精确理解某个模型行为的开发者。

## 它解决什么问题

普通的对话 Playground（OpenAI / Anthropic 官方那种）有几个限制：

1. **只能 append**：你只能在最后追加一条消息，无法编辑历史
2. **不能伪造 assistant 输出**：你说不了"假设模型上一轮回答的是 X"
3. **不能伪造 tool_result**：调用工具就一定要真跑，无法手填假数据
4. **不能在中间插入**：插不了一段假的 tool_use / tool_result 来探测模型反应

这些是调 agent 时最常需要的能力。本工具把"消息历史"当成一个**可任意编辑的 JSON 数组**，
每一条 message、每一个 content block 都是一个普通表单字段，改完点 Send 就发。

## 核心心智模型

LLM 是 stateless 的。让模型"以为它说过 X" 等价于：把 messages 数组里那条改成 X，下次请求带上。

整个工具就是这一句话的具象化：

```
[你看到 assistant 回了 "天气是晴"]
       ↓ 你直接改 → "天气是暴雨"
[模型看到的历史里就成了 "天气是暴雨"]
       ↓ Send
[基于 "天气是暴雨" 的上下文继续]
```

没有"原始" vs "修改后"的概念——历史就是当前 messages 数组的样子。

## 不解决什么

- 不是生产 agent 框架（不要在用户面前用它）
- 不是 prompt 版本管理工具（虽然 cases 可以提交到 git）
- 不内建 evaluation / scoring（自己看输出做判断）

## 跟其他工具比

| | llm-impl | OpenAI Playground | Promptfoo / LangSmith |
|---|---|---|---|
| 编辑历史消息 | ✅ 任意一条 | ❌ | ❌ 看不能改 |
| 伪造 assistant tool_use | ✅ | ❌ | ❌ |
| 手填 tool_result | ✅ | ❌ | 部分 |
| 多 provider | ✅ 任意 OpenAI / Anthropic 兼容 | 单家 | ✅ |
| 流式 + 思考块 | ✅ | ✅ | ✅ |
| 调试用例文件 | ✅ JSON in git | ❌ | ✅ YAML |
| 自动 eval | ❌ | ❌ | ✅ |

它就是一个**调试**工具，不是评估工具，也不是部署工具。
